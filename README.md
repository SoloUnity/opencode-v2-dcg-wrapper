# opencode-v2-dcg-wrapper

Checks OpenCode V2 shell commands with [DCG](https://github.com/Dicklesworthstone/destructive_command_guard).

Install DCG. Set the `DCG_BIN` constant in `opencode-v2-dcg-wrapper.js` to its path.
Copy that file to `~/.config/opencode/plugins/`. OpenCode loads it automatically.
